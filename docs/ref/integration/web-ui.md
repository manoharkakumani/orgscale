# Web interfaces for orgscale

!!! warning "Community contributions"

    This page contains community contributions. The projects listed here are not
    maintained by the orgscale authors and are written by community members.

Orgscale doesn't provide a built-in web interface but users may pick one from the available options.

- [orgscale-ui](https://github.com/gurucomputing/orgscale-ui)
    - ![GitHub stars](https://img.shields.io/github/stars/gurucomputing/orgscale-ui?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/gurucomputing/orgscale-ui)
    - A web frontend for the orgscale Tailscale-compatible coordination server
- [OrgscaleUi](https://github.com/simcu/orgscale-ui)
    - ![GitHub stars](https://img.shields.io/github/stars/simcu/orgscale-ui?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/simcu/orgscale-ui)
    - A static orgscale admin ui, no backend environment required
- [Headplane](https://github.com/tale/headplane)
    - ![GitHub stars](https://img.shields.io/github/stars/tale/headplane?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/tale/headplane)
    - An advanced Tailscale inspired frontend for orgscale
- [orgscale-admin](https://github.com/GoodiesHQ/orgscale-admin)
    - ![GitHub stars](https://img.shields.io/github/stars/GoodiesHQ/orgscale-admin?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/GoodiesHQ/orgscale-admin)
    - Orgscale-Admin is meant to be a simple, modern web interface for orgscale
- [ouroboros](https://github.com/yellowsink/ouroboros)
    - ![GitHub stars](https://img.shields.io/github/stars/yellowsink/ouroboros?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/yellowsink/ouroboros)
    - Ouroboros is designed for users to manage their own devices, rather than for
      admins
- [unraid-orgscale-admin](https://github.com/ich777/unraid-orgscale-admin)
    - ![GitHub stars](https://img.shields.io/github/stars/ich777/unraid-orgscale-admin?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/ich777/unraid-orgscale-admin)
    - A simple orgscale admin UI for Unraid, it offers Local (`docker exec`) and
      API Mode
- [orgscale-console](https://github.com/rickli-cloud/orgscale-console)
    - ![GitHub stars](https://img.shields.io/github/stars/rickli-cloud/orgscale-console?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/rickli-cloud/orgscale-console)
    - WebAssembly-based client supporting SSH, VNC and RDP with optional
      self-service capabilities
- [orgscale-piying](https://github.com/wszgrcy/orgscale-piying)
    - ![GitHub stars](https://img.shields.io/github/stars/wszgrcy/orgscale-piying?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/wszgrcy/orgscale-piying)
    - orgscale web ui, support visual ACL configuration
- [HeadControl](https://github.com/ahmadzip/HeadControl)
    - ![GitHub stars](https://img.shields.io/github/stars/ahmadzip/HeadControl?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/ahmadzip/HeadControl)
    - Minimal Orgscale admin dashboard, built with Go and HTMX
- [Orgscale Manager](https://github.com/hkdone/orgscalemanager)
    - ![GitHub stars](https://img.shields.io/github/stars/hkdone/orgscalemanager?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/hkdone/orgscalemanager)
    - Orgscale UI for Android
- [Orgscale UI](https://github.com/MunMunMiao/orgscale-ui)
    - ![GitHub stars](https://img.shields.io/github/stars/MunMunMiao/orgscale-ui?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/MunMunMiao/orgscale-ui)

- [Orgscale Panel](https://github.com/orgscale-panel/panel)
    - ![GitHub stars](https://img.shields.io/github/stars/orgscale-panel/panel?style=flat)
