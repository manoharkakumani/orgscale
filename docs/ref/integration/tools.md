# Tools related to orgscale

!!! warning "Community contributions"

    This page contains community contributions. The projects listed here are not
    maintained by the orgscale authors and are written by community members.

This page collects third-party tools, client libraries, and scripts related to orgscale.

- [orgscale-operator](https://github.com/infradohq/orgscale-operator)
    - ![GitHub stars](https://img.shields.io/github/stars/infradohq/orgscale-operator?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/infradohq/orgscale-operator)
    - Orgscale Kubernetes Operator
- [tailscale-manager](https://github.com/singlestore-labs/tailscale-manager)
    - ![GitHub stars](https://img.shields.io/github/stars/singlestore-labs/tailscale-manager?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/singlestore-labs/tailscale-manager)
    - Dynamically manage Tailscale route advertisements
- [orgscalebacktosqlite](https://github.com/bigbozza/orgscalebacktosqlite)
    - ![GitHub stars](https://img.shields.io/github/stars/bigbozza/orgscalebacktosqlite?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/bigbozza/orgscalebacktosqlite)
    - Migrate orgscale from PostgreSQL back to SQLite
- [orgscale-pf](https://github.com/YouSysAdmin/orgscale-pf)
    - ![GitHub stars](https://img.shields.io/github/stars/YouSysAdmin/orgscale-pf?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/YouSysAdmin/orgscale-pf)
    - Populates user groups based on user groups in Jumpcloud or Authentik
- [orgscale-client-go](https://github.com/hibare/orgscale-client-go)
    - ![GitHub stars](https://img.shields.io/github/stars/hibare/orgscale-client-go?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/hibare/orgscale-client-go)
    - A Go client implementation for the Orgscale HTTP API.
- [orgscale-zabbix](https://github.com/dblanque/orgscale-zabbix)
    - ![GitHub stars](https://img.shields.io/github/stars/dblanque/orgscale-zabbix?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/dblanque/orgscale-zabbix)
    - A Zabbix Monitoring Template for the Orgscale Service.
- [tailscale-exporter](https://github.com/adinhodovic/tailscale-exporter)
    - ![GitHub stars](https://img.shields.io/github/stars/adinhodovic/tailscale-exporter?style=flat)
      ![GitHub last commit](https://img.shields.io/github/last-commit/adinhodovic/tailscale-exporter)
    - A Prometheus exporter for Orgscale that provides network-level metrics using
      the Orgscale API.
